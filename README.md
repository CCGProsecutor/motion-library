# Motion Library

一个可搜索、筛选并试玩网页动效的静态目录，整理了 331 个文字、按钮、卡片、图形、背景、版面与游标效果。

## 本地运行

无需构建工具，使用任意静态服务器即可：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 交互

- 搜索名称、英文名、描述、标签和实现技术
- 按元件、时机、情境和技术筛选
- 切换元件分组或最新收录排序
- 自定义预览文字
- 卡片进入视口时才启动动画，离开后自动清理
- 复制每个效果的 AI 提示词
- 移动端收起筛选与顶部快捷栏

动画预览仅用于学习和原型参考，数据与效果实现集中在 `data.js`、`fx.js` 与 `fx.css`。
